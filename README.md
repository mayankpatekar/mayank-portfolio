# Mayank Patekar — Developer Portfolio

A modern, responsive portfolio built with Next.js, React and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

Update these values in `app/page.js`:
- Email address
- LinkedIn URL
- GitHub URL
- Project GitHub/live-demo links if available

You can deploy the project easily to Vercel after pushing it to GitHub.
